# Historical development archive

These files record the specifications, prompts, research and plans that directed
AI-assisted development. They are preserved for ETHGlobal provenance requirements.
They are **not current setup instructions, presentation claims or completion reports**.
Use the [current documentation](../README.md) and [verified evidence](../LIVE-EVIDENCE.md).

- [PRD.md](PRD.md): original requirements and embedded contracts/prompt/policy reference.
- [PITCH_PLAN.md](PITCH_PLAN.md): original scenario and presentation plan.
- [DESIGN.md](DESIGN.md), [UX-CONTRACT.md](UX-CONTRACT.md), [BRAND-DIRECTION.md](BRAND-DIRECTION.md): earlier design directions.
- [pitch-deck.md](pitch-deck.md): earlier Wallet Audit Trail concept.
- [HACKATHON-MVP.md](HACKATHON-MVP.md), [FINALISATION-PLAN.md](FINALISATION-PLAN.md): historical implementation plans.
- [website-deployment.md](website-deployment.md): the first static-only website release.
- [submission-draft.md](submission-draft.md): superseded submission draft.
- [ai-development-log.md](ai-development-log.md): detailed historical assistance log, including unconfirmed assertions.
- [rehearsal-history.md](rehearsal-history.md): chronological failures, reconciliation and subsequent verification.
- [research/](research/): original external-API research memos.

Original text is preserved, including paths and dates as written. Relative links inside
these historical documents may reflect their original locations. Refer to the repository
history for that original layout. Retaining these records does not confirm an unverified
claim about authorship, creation time or deployment. The team must confirm provenance
in [AI usage](../ai-usage.md) before submission.

The original PRD remains a test reference for byte-exact analyst prompts and the fixture
generator's policy fallback. Current runtime behaviour is defined by source and tests.
